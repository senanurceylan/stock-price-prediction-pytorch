# Stock Price Prediction with PyTorch

## English

This project is an AI-powered stock price prediction platform built with Python and PyTorch. It uses historical stock market data to train an LSTM-based deep learning model and predict future stock price movements.

The project is designed to gradually include:

- Historical stock data collection and preprocessing
- PyTorch LSTM model training and prediction
- Model evaluation and actual-vs-predicted visualizations
- Interactive dashboard for stock analysis
- Redis caching to reduce repeated data requests and improve response time
- Azure integration for cloud deployment, model/data storage, and scalable services
- Optional AI-assisted explanations of prediction results

> The main goal of the project is to combine time-series forecasting, deep learning, backend technologies, and cloud services in a practical stock market application.

## Türkçe

Bu proje, Python ve PyTorch kullanılarak geliştirilen yapay zekâ destekli bir hisse senedi fiyat tahmin platformudur. Geçmiş borsa verileri kullanılarak LSTM tabanlı bir derin öğrenme modeli eğitilecek ve gelecekteki hisse fiyat hareketleri tahmin edilmeye çalışılacaktır.

Projenin aşamalı olarak içermesi planlanan özellikler:

- Geçmiş hisse senedi verilerinin alınması ve ön işlenmesi
- PyTorch LSTM modelinin eğitilmesi ve tahmin yapılması
- Model performansının değerlendirilmesi ve gerçek-tahmin grafiklerinin oluşturulması
- Hisse analizi için etkileşimli bir dashboard
- Tekrarlanan veri isteklerini azaltmak ve yanıt süresini iyileştirmek için Redis cache entegrasyonu
- Cloud deployment, model/veri saklama ve ölçeklenebilir servisler için Azure entegrasyonu
- Tahmin sonuçlarını açıklamak için isteğe bağlı yapay zekâ destekli analiz özelliği

> Projenin temel amacı; zaman serisi tahmini, derin öğrenme, backend teknolojileri ve cloud servislerini gerçek bir borsa uygulaması üzerinde bir araya getirmektir.
